# 个人站独立样品

用户已确认：可以做独立的样品，模拟回答，不消耗我的额度。

## Constraints
- 正式站、正式数据和访问权限不变。
- 五个样品只用虚拟数据；AI 回答来自标明的预设示例。
- 不连接正式后台、Codex、ima 或任何模型接口。
- 每个样品使用独立的浏览器存储键；重置仅删除当前样品的数据。
- 个人站五个项目的主按钮进入样品，不公开正式站地址。

## 结构与操作
GitHub Pages 的 public/projects/codex-samples 下发布五个独立入口，共用静态外壳和纯本地状态模块。
小红果模拟播放进度与双人同步；藏宝库提供虚拟资料搜索、添加笔记和预设问答；自有引力提供机会收藏、试单和利润计算；貅知识提供目标、笔记、测验与预设学习回答；地底余烬提供格子挖矿与背包。
界面持续标明独立样品、模拟回答、不调用模型，不冒充真实跨设备同步或真实 AI。

## 验收
语法检查、状态与存储隔离测试、禁止网络调用检查、构建发布检查。
验证五个样品和个人站线上资源；浏览器连接不可用时准确报告验证范围。
