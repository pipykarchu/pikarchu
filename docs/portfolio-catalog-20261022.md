# 作品目录与展示交互

## 内容归属

所有作品统一维护在 `content/projects.json`，领域维护在 `content/categories.json`。

- 工作：通过 `workType` 分为 `project`（项目）、`tool`（工具）、`method`（技能与模板）。
- 学习、内容创作、生活：保留各自领域。
- Mozin 与云灵汐位于工作项目；云灵汐保留“参与规划与设计”的责任描述。
- 飞书联动、SOP 与模板技能位于工作方法。
- 公开归档通过每项的 `archive` 与 `actions` 进入，不再单独占一个首页展示区。

`sourceLabel` 用于区分工作项目、工作沉淀与个人作品。`role`、`period`、`scope` 在详情中保留职责、阶段与范围。`case` 表示阶段成果，`documented` 表示已沉淀的方法，不作为生产上线证明。

## 展示交互

桌面端以目录配合实时预览，鼠标经过或键盘聚焦时切换预览，点击展开详情。手机端通过目录直接打开详情。页面包括滚动出现、预览过渡、轻微指针视差及貔貅轨道动效。

音效默认关闭。用户手动开启后，只在点击筛选或作品时播放短提示音；悬停、自动滚动与页面载入均不播放。音频能力不可用时开关禁用，播放失败时恢复关闭。

新增动效响应 `prefers-reduced-motion`。详情支持 Escape 关闭、Tab 焦点循环和关闭后回到原按钮。

原 `#work-portfolio`、`#work-methods`、`#work-archives` 链接继续映射到工作目录；方法链接会选中对应筛选。

## 验证范围

完成正式构建、组件服务端渲染、数据保留与归档路径检查。使用模拟音频上下文验证静音默认值、显式开启、关闭后不再触发及短音量包络。未执行本轮真实浏览器视觉、实际扬声器或耳机听感验收。
